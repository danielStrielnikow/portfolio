SeeTrade LTD

Rola: Backend Developer  ·  Tech: Java 21, Spring Boot 3.5, PostgreSQL, Redis, Docker

Zaawansowane MVP platformy logistycznej do transportu pojazdów. Klienci składają zlecenia podając szczegóły pojazdu i trasy; przewoźnicy przeglądają dostępne zlecenia i je podejmują. System zarządza pełnym cyklem życia zlecenia — od złożenia, przez przydzielenie przewoźnika, po śledzenie statusu transportu.

Kluczowe wkłady:

• Zaprojektowanie modelu domenowego: klienci, przewoźnicy, pojazdy, zlecenia transportowe
• Implementacja logiki przydzielania przewoźników z pesymistycznym blokowaniem bazy danych (race condition przy równoczesnym podejmowaniu zlecenia)
• Projektowanie REST API i optymalizacja zapytań SQL z indeksami złożonymi
• Cache Redis dla danych referencyjnych z inwalidacją TTL

BMW Telemetry System

Rola: Twórca (Projekt IoT)  ·  Tech: OBDII, CAN bus, WebSocket, Java

System diagnostyki pojazdu w czasie rzeczywistym zbudowany na protokole OBDII. Odczytuje dane na żywo z magistrali CAN — obroty, temperatura silnika, napięcie, kody błędów — i przesyła je przez WebSocket do panelu przeglądarki.

Kluczowe wkłady:

• Parsowanie ramek OBDII i mapowanie PID
• Strumieniowanie danych w czasie rzeczywistym przez WebSocket do live dashboardu
• Odczyt i kasowanie kodów błędów (DTC)

Kluczowe wkłady:

• Wykrywanie orientacji przez akcelerometr (MPU-6050)
